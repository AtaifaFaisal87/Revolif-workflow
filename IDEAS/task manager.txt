USER AND TASK MANAGER
The User has a composition relationship with TaskManager because tasks are personal data that belong to a specific user.
Each User contains their own TaskManager, which manages their Academic and Daily Tasks.
When a User exists, their TaskManager and tasks exist with them, and the tasks are linked to that user's ID.
