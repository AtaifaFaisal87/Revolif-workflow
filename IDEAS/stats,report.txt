================ STATISTICS CLASS ================


The Statistics class is responsible for analyzing data from different modules and generating reports.

It does not store original data.

It only reads data from managers.

================ STATISTICS RELATIONSHIPS ================


Statistics has an association relationship with all managers.


It reads data from:


TaskManager

GoalManager

ExpenseManager

HealthManager

AchievementManager



Example:


TaskManager

        |

        ↓

Statistics

        |

        ↓

Task Report



====================================================================



================ USER AND STATISTICS RELATIONSHIP ================


The User has a composition relationship with Statistics because each user requires their own personal reports and analysis.


Each User contains a Statistics object that analyzes the user's personal data.


Example:


User A

|

Statistics

|

Reads:

- User A Tasks
- User A Goals
- User A Expenses
- User A Health Records



User B will have separate statistics based only on User B's data.



====================================================================



================ ADMIN AND STATISTICS RELATIONSHIP ================


Admin has access to AdminStatistics.

AdminStatistics provides system-level reports.

It does not access private user details such as:

- Personal health records
- Personal expenses
- Personal goals
- Personal tasks


It only accesses required system information.

================ DESIGN REASONING ================


Statistics does not store module data.

Each manager is responsible for its own data.

Statistics only collects, analyzes, and displays information.

User statistics are private and generated from individual user modules.

Admin statistics are system-level and used for monitoring application performance.

This design maintains:

- Data privacy
- Separation of responsibilities
- Modular architecture
- Easy future expansion


Future Extensions:

- AI productivity analysis
- Smart recommendations
- Monthly productivity score
- Spending predictions
- Health trends
- Goal completion predictions
- Admin analytics dashboard
