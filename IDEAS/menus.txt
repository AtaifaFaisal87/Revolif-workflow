================ AUTOMATIC DATA SAVING SYSTEM ================


Users do not manually save data.

The system automatically saves data using FileManager.


Working:


User performs an operation

|

↓

Manager updates data

|

↓

FileManager automatically saves changes

|

↓

Data stored permanently



Examples:


Add Task

↓

TaskManager updates task list

↓

FileManager saves tasks



Add Goal

↓

GoalManager updates goal list

↓

FileManager saves goals



Add Expense

↓

ExpenseManager updates transactions

↓

FileManager saves transactions



Add Health Record

↓

HealthManager updates health records

↓

FileManager saves health data



Logout / Application Close:


|

↓

System automatically saves all user data

|

↓

User session ends

================ DESIGN REASONING ================


- Each module has its own responsibility.
- Managers handle data storage and operations.
- Statistics only analyzes data and generates reports.
- AI Assistant is integrated only inside Health Manager for symptom analysis.
- FileManager automatically handles saving and loading.
- Users can only access their own personal data.
- Admin can view system-level statistics but cannot access private user information.

This keeps the system modular, secure, and scalable.
